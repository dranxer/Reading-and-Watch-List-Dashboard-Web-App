🔍 YouTube Debug Instructions

⚠️ YouTube Detection Not Working?
Follow these steps to debug the issue and get detailed information about what's happening.

🔧 Step 1: Reload Extension

1. Go to chrome://extensions/
2. Find "ReadWatch Tracker" extension
3. Click the "Reload" button (🔄)
4. Make sure the extension is enabled

📺 Step 2: Test on YouTube

1. Go to any YouTube video (e.g., https://youtube.com/watch?v=dQw4w9WgXcQ)
2. Open browser console (F12 → Console tab)
3. Look for ReadWatch logs starting with "📚" or "🔍"
4. Wait 10 seconds for all logs to appear

📝 Step 3: Check Console Logs

You should see logs like these in the console:

🔍 YouTube Debug Script Starting... 📍 Current URL: https://www.youtube.com/watch?v=... 📍 Hostname: www.youtube.com 📍 Pathname: /watch 🎬 YouTube Detection: - Is YouTube domain: true - Is video page: true - Has video ID: true 📚 ReadWatch Tracker: Content script loaded on ... 📚 YouTube detected - using extended delay 📚 Current URL: https://www.youtube.com/watch?v=... 📚 Is watch page: true

If you DON'T see these logs:

  • The extension might not be loading on YouTube
  • Try reloading the extension and refreshing YouTube
  • Check if the extension is enabled

🎯 Step 4: Check Content Detection

Look for these specific logs after ~3-10 seconds:

📚 Starting content analysis... 📚 Checking if page should be filtered... 📚 YouTube video page - NOT filtering 📚 Extracting YouTube video content... 📚 Raw title: [Video Title] - YouTube 📚 Clean title: [Video Title] 🔍 Testing YouTube Content Selectors... 📝 Title Testing: ✅ h1.ytd-video-primary-info-renderer: "[Video Title]" 📄 Description Testing: ✅ #description: "[Description...]"

🚨 Common Issues & Solutions

Issue 1: No logs appear at all

  • Solution: Extension not loading - reload extension and refresh page
  • Check: Extension is enabled in chrome://extensions/

Issue 2: Extension loads but no YouTube detection

  • Check: Are you on a /watch page? (not homepage or channel page)
  • Try: Wait longer - YouTube takes time to load content

Issue 3: Selectors not finding content

  • Solution: YouTube layout may have changed
  • Check: Look at the selector test results in console
  • Report: Copy the console output to help fix selectors

Issue 4: Content extracted but not saved

  • Check: Look for "💾 Saving content..." logs
  • Check: Extension popup to see if items appear

📊 Step 5: Test Results

If YouTube detection still isn't working, copy the debug template and fill it out with your console logs.

🔄 Quick Fixes to Try

  1. Reload extension in chrome://extensions/
  2. Refresh YouTube page and wait 10 seconds
  3. Try different YouTube videos (some may load differently)
  4. Clear browser cache and try again
  5. Try in incognito mode with extension enabled
